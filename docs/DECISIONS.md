## החלטות פתוחות
- בחירת/קבלת כרטיס חלופי תקין ובדיקת נפחו; אין מערכת מותקנת ומאומתת. לוודא צורך בגיבוי בכרטיס החלופי לפני צריבה.
- תקינות הקורא החיצוני טרם הוכרעה; אפשר לעקוף אותו עם Network Install ב־Pi.
- מקור הזנת הסרוו, מודול הברדבורד ומיפוי GPIO.
- מידות חטיפים, מהלך המנגנון וטווח זוויות בטוח.
- מימוש מדיה סופי ויעדי רזולוציה, קצב תמונה והשהיה לכל לוח.
- ספק VPS, שיטת אימות משתמשים ופרטי הגישה המרוחקת.
- אופן מניעת שחרורים כפולים והגבלות כמות/קצב.
- השלמת המעבר לתיעוד ב־docs/ במאגר; כרגע המסמכים טרם הועלו.
- מי מוביל חיווט ושילוב.
