### תקלה שאותרה ותוקנה: ניתוקי Wi-Fi מדי פעם
תסמין: SSH מתנתק מדי כמה דקות, ול-dogshitter.local "אי אפשר למצוא" למשך כמה שניות ואז חוזר.
אבחון: `dmesg` הראה `brcmfmac: brcmf_cfg80211_set_power_mgmt: power save enabled` — חיסכון בחשמל ב-Wi-Fi גורם לניתוקים קצרים מחזוריים.
תיקון: `sudo iw wlan0 set power_save off` (מיידי) + `sudo nmcli connection modify "netplan-wlan0-F JOE BIDEN" wifi.powersave 2` (קבוע, שורד ריבוט).
תוצאה: טרם אומת סופית על פני זמן ארוך — יש לעקוב אם הניתוקים חזרו.
ממצא משני: הצטברו כ-25 תהליכי vscode-server על ה-Pi משאריות חיבורים קודמים שלא נסגרו — מומלץ לסגור את כל חלונות ה-VS Code המחוברים ולפתוח מחדש כדי לנקות.

### 2026-09-25 — SW-06: VPS חינמי הוקם על Oracle Cloud
- תאריך ומזהה משימה: 2026-09-25, SW-06.
- מה בוצע בפועל: נוצר חשבון Oracle Cloud (Home Region: Israel Central/Jerusalem, נבחר לאחר בדיקה שבעיית "אין קיבולת" ל-Ampere A1 אינה ייחודית לישראל אלא בעיה כללית של Oracle Always Free בכל region). נוצרה מכונה בשם `kora-signaling` (shape: VM.Standard.E2.1.Micro, Always Free — לא Ampere A1, כדי להימנע לגמרי מסיכון הקיבולת; 1 OCPU / 1GB RAM, מספיק לעומס של שרת איתות + TURN). מערכת הפעלה: Ubuntu 24.04 LTS (לא Oracle Linux, לעקביות עם ה-Pi שמבוסס Debian/apt). נוצר VCN+subnet ציבורי ייעודי דרך "VCN Wizard" (הדרך המקוצרת בתוך יצירת המכונה לא הקימה Internet Gateway כראוי). נוספו שני מפתחות SSH (ed25519): אחד ייעודי לעוזר (`claude-kora-vps`, פרטי נשאר אצל העוזר בלבד) ואחד של איתי (`itai-kora-vps`, נוצר במחשב Windows). נוסף קובץ swap בגודל 1GB (המכונה ללא swap כברירת מחדל, עם 1GB RAM בלבד).
- קבצים והגדרות שהשתנו: `/swapfile` על ה-VPS (1GB, הרשאות 600, מופעל דרך `swapon`), שורה נוספה ל-`/etc/fstab` (`/swapfile none swap sw 0 0`) כדי שה-swap ישרוד ריבוט.
- בדיקה ותוצאה: התחברות SSH ל-`151.145.95.142` עם מפתח העוזר עברה בהצלחה (`ubuntu@151.145.95.142`); `lsb_release -a` אישר Ubuntu 24.04.5 LTS; `free -h` אחרי ההגדרה מראה `Swap: 1.0Gi` פעיל ו-0 בשימוש.
- ניסיון שלא עבד והסיבה: הניסיון הראשון ליצור VCN+subnet ציבורי דרך הקיצור המובנה במסך יצירת המכונה נכשל — הכפתור "Automatically assign public IPv4 address" נשאר מנוטרל כי אותו קיצור לא מקים Internet Gateway/חוקי ניתוב מלאים. נפתר על ידי יצירת VCN בנפרד דרך "VCN Wizard" הייעודי (עם קישוריות אינטרנט), ואז בחירת אותו VCN/subnet קיימים במסך יצירת המכונה.
- החלטות לעדכון ב-DECISIONS.md: נוספו החלטות על בחירת Oracle Cloud Always Free (ולא VPS בתשלום), Home Region ישראל, shape E2.1.Micro (לא Ampere A1), ו-Ubuntu 24.04.
- מצב וחסמים: ה-VPS קיים ופעיל, נגיש ב-SSH. עדיין לא הותקן עליו שום דבר פונקציונלי (לא שרת איתות, לא coturn).
